Unicode Twins

Find every copy of the target character. Some of the others only look like it.

Each level has 8 rounds. Select every tile holding exactly the same Unicode character as the target, then press Check. +1 for each correct pick, −1 for each wrong one, +2 bonus for a perfect round. After each round you'll see the code point behind every tile.
